# DaMS4 Festival App

Application de gestion de festival pour le projet DaMS4.

## 🚀 Démarrage Rapide

Pour configurer et lancer le projet sur votre machine, consultez le **[Guide de Configuration](SETUP.md)**.

## 📖 Documentation

- **[SETUP.md](SETUP.md)** - Guide complet d'installation et de configuration
- **Architecture** : Frontend Angular + Backend Express + PostgreSQL
- **Sécurité** : HTTPS local avec mkcert, authentification JWT

## 🛠️ Stack Technique

- **Frontend** : Angular 20, TypeScript, Angular Material
- **Backend** : Node.js, Express, TypeScript
- **Base de données** : PostgreSQL 16 (Docker)
- **Outils** : Docker Compose, mkcert (certificats SSL)

## 📝 Liens Utiles

- **Frontend** : https://localhost:4200
- **Backend API** : https://localhost:4000
- **Adminer (DB)** : http://localhost:8080
